# Demo Vertical Slice

## Goal

Membuktikan bahwa satu rental dapat dikelola dari booking sampai event lokasi, return, dan maintenance tanpa berpindah-pindah sistem.

## Slice checklist

- [ ] Owner membuat satu unit motor.
- [ ] Owner mengatur harga dan lokasi pickup.
- [ ] Customer membuka storefront/link rental.
- [ ] Customer memilih waktu dan unit.
- [ ] Customer melihat total dan aturan.
- [ ] Customer mengirim booking.
- [ ] Owner approve dan mengonfirmasi pickup.
- [ ] Rental Session menjadi Active.
- [ ] GPS HP customer mengirim lokasi demo.
- [ ] Owner melihat last seen di map.
- [ ] Owner membuat satu geofence polygon.
- [ ] Sistem menghasilkan event enter/exit.
- [ ] Owner melihat contextual alert.
- [ ] Owner menyelesaikan return.
- [ ] Owner mengisi inspection.
- [ ] Maintenance task dapat dibuat.
- [ ] Unit keluar dari availability selama maintenance.

## Explicitly out of scope

- Payment gateway production.
- Hardware tracker production.
- Marketplace discovery.
- Advanced analytics.
- Automated danger-zone recommendations.

## Definition of done

- Customer dapat menyelesaikan booking tanpa penjelasan manual.
- Owner memahami tindakan utama dalam satu layar.
- Alert menunjukkan konteks lengkap dan dapat ditangani.
- Demo memakai data yang saling terhubung, bukan halaman fixture yang berdiri sendiri.
