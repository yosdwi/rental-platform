# Contributing

## Bentuk kontribusi

- Product decision: update ADR dan decision log.
- UX/research: update dokumen research, flow, atau design system dengan sumber dan implikasi produk.
- Implementation: buat perubahan kecil yang mendukung satu vertical slice.
- QA: catat skenario, hasil, dan bukti pada handoff.

## Commit convention

Gunakan prefix sederhana:

- `docs:` dokumentasi dan decision log
- `ux:` flow, design system, atau copy
- `feat:` capability baru
- `fix:` perbaikan bug
- `chore:` tooling dan repository setup

## Pull request

Setiap PR menjelaskan:

1. Masalah yang diselesaikan.
2. Scope yang sengaja tidak dikerjakan.
3. Dokumen keputusan/flow yang relevan.
4. Cara memverifikasi.
5. Risiko dan langkah lanjutan.
